# High-Level System Architecture

This directory contains the high-level architecture diagram for the AI Personalized Learning Platform.

## Files

- `High_Level_Architecture.drawio`: editable source for diagrams.net/Draw.io.
- `High_Level_Architecture.png`: raster preview for Jira, README, and document embedding.
- `High_Level_Architecture.svg`: scalable vector export.

## Diagram conventions

- Solid connectors represent components or dependencies implemented in the current repository.
- Dashed connectors represent planned components or integrations.
- The frontend currently uses `AuthContext` and `localStorage` for mock authentication.
- Frontend-to-backend REST integration and the AI Core Engine are planned and are not yet implemented in the current repository.
